# Buck5V3A
5V, 3A (max) Regulator SCAB

Design and support files for the 5V, 3A regulator SCAB.

This SCAB is a small (1.3"x0.7") PCB that contains a TPS62933 regulator.  Adjusting the feedback resistors allows other voltages to be attained (within the limits of the supply voltage range and the TPS62933 design requirements).

Gerber files are included as well as a step file representation of the SCAB.  The schematic has integrated BOM and assembly view allowing for a single document to control fabrication.
